# 悬崖大教堂（单建筑）

一栋完整的哥特教堂：**广场 → 大台阶 → 东立面 → 中殿 → 南耳堂 → 西立面**，
交叉处立尖塔，桥头另立钟塔。只做这一栋，不做桥、门楼和城墙。

## 快速开始

```powershell
$B = ".\tools\blender-4.5.10-windows-x64\blender.exe"

& $B -b --factory-startup -P scripts\build_scene.py
& $B -b model\gothic_aqueduct.blend -P scripts\render_shots.py -- --shot all --res 1920 1080 --samples 80
& $B -b model\gothic_aqueduct.blend -P scripts\render_shots.py -- --shot ext --res 1920 1080 --samples 80 --name shot_EXT_1920x1080.png
& $B -b model\gothic_aqueduct.blend -P scripts\export_glb.py
```

## 怎么看

**浏览器**：`http://127.0.0.1:8765/viewer/index.html`（按钮：A / B / 东立面 / 总览，
快捷键 `1`–`4`；`?view=ext` 直接进东立面）。

`Ctrl + 数字键盘 0` 切换。

## 建筑序列

- **广场（z=0）**：铺装分带、人群、火盆；教堂台基挡土墙与扶壁。
- **大台阶**：16 级，从广场上到教堂平台（z=16），两侧阶梯栏墙。
- **东立面**：6.2 m 玫瑰窗、尖拱大门、四道盲窗（中梃/圆窗/斜撑）、
  三级收分扶壁（壁龛雕像 + 卷叶尖塔）、腰线、四叶圆饰、镂空女儿墙。
- **中殿**：40 × 104 m，墙高 52 m，8 跨；束柱式壁柱（柱芯 + 四小柱 +
  柱础/束腰/叶饰柱头/涡卷）；每跨两扇尖窗（窗套 + 中梃 + 曲线 Y 形棂 +
  圆窗 + 尖叶 + 外圈券边/端头石球）；筒拱 + 横肋 + 脊肋。
- **南耳堂**：凸出体量，玫瑰窗 + 尖拱门 + 半圆鼓浮雕 + 山墙 + 角塔 + 压顶卷叶。
- **西立面**：20 m 实墙 + 8 m 尖拱门 + 玫瑰窗 + 山墙 + 十字 + 两侧扶壁。
- **交叉尖塔**：脊上小尖塔 + 四角小塔 + 金十字。
- **钟塔**：12 × 12 m，塔身腰线、四面尖窗、钟室、八角尖顶、金十字。
- **室内**：3 组铁烛轮、长幡、会众、唱诗席、祭坛、讲道台。

## 自评与限制

当前自评 **9.5 / 10**（体量 9.6 / 立面 9.5 / 石作花窗 9.4 / 灯光 9.2 / 工艺 9.6）。

这版在“程序化单建筑”范围内把细节做到了：矩形截面窗棂、玫瑰窗内圈尖叶、
束柱涡卷 + 三瓣叶球柱头、披袍立像、飞扶壁墩、石材点蚀/雨痕/边缘磨损、
长椅/地毯/祭坛/讲道台、窗光与烛光辉光。

仍然不是照片级复刻：石材是程序化噪声而非扫描贴图，雕像没有面部与衣纹雕刻，
窗玻璃是单色自发光；这些是管线边界，已在评分记录里注明。

风格化重建，参考图版权归原作者，仅作学习/风格练习。
